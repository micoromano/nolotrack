# Allegati su Cloudflare R2

NoloTrack salva le foto di scontrini e ricevute (e qualsiasi PDF) in un bucket
**Cloudflare R2**. Gli allegati si aggiungono dalla pagina di modifica di una
**spesa**, di un **rifornimento** o di una **corsa** (sezione *Allegati*).
Finché R2 non è configurato la sezione non compare.

- Formati: JPG, PNG, WEBP, HEIC, PDF — max 10 MB, max 10 allegati per voce.
- Le foto sopra 1,5 MB vengono ridimensionate nel browser (lato lungo 2000 px,
  JPEG 85%) prima dell'upload.
- Il bucket resta **privato**: i file si aprono solo da NoloTrack, con link
  firmati validi 5 minuti.

## Come funziona

```
browser ──POST /api/allegati──────────────▶ app: verifica voce (RLS), registra riga
        ◀── URL firmato (PUT, 5 min) ──────       `allegati` con caricato=false
browser ──PUT file──────────────────────────▶ R2   (il file non passa dall'app)
browser ──POST /api/allegati/:id/conferma──▶ app: HEAD su R2, controlla dimensione
                                                 e tipo, imposta caricato=true
```

- Chiave nel bucket: `allegati/<autista>/<spesa|carburante|corsa>/<id>.<ext>`
  (il nome originale del file resta solo nel database).
- Eliminando un allegato, o la voce a cui appartiene (cascata), un trigger mette
  la chiave in `allegati_da_eliminare`. L'app prova a cancellare subito il file;
  quelli rimasti li elimina la **pulizia notturna** (`/api/allegati/pulizia`),
  che scarta anche gli upload iniziati e mai confermati da più di 24 ore.

## Configurazione

### 1. Bucket

Cloudflare dashboard → **R2 Object Storage** → *Create bucket*, es. `nolotrack`.
Location automatica (o *EU* per tenere i dati in Europa: in quel caso
l'endpoint è `https://<ACCOUNT_ID>.eu.r2.cloudflarestorage.com`, da mettere in
`R2_ENDPOINT`). **Non** abilitare l'accesso pubblico né un dominio pubblico.

### 2. CORS del bucket

Serve perché il browser carica il file direttamente su R2. Bucket → *Settings*
→ *CORS Policy* → *Add CORS policy*, sostituendo l'origine con quella dell'app:

```json
[
  {
    "AllowedOrigins": ["https://nolotrack.miodominio.it"],
    "AllowedMethods": ["PUT", "GET"],
    "AllowedHeaders": ["content-type"],
    "MaxAgeSeconds": 3600
  }
]
```

Aggiungi anche `http://localhost:3000` se sviluppi in locale.

### 3. Token API

R2 → *Manage R2 API Tokens* → *Create API token*:
- Permessi: **Object Read & Write**
- Bucket: solo `nolotrack`

Copia *Access Key ID* e *Secret Access Key* (il secret si vede una volta sola).
L'*Account ID* è nella pagina principale di R2.

### 4. Variabili d'ambiente

| Variabile | Valore |
|---|---|
| `R2_ACCOUNT_ID` | Account ID Cloudflare |
| `R2_ACCESS_KEY_ID` | dal token API |
| `R2_SECRET_ACCESS_KEY` | dal token API (**segreto**) |
| `R2_BUCKET` | `nolotrack` |
| `R2_ENDPOINT` | facoltativo: bucket EU o altro storage S3 (es. MinIO) |
| `CRON_SECRET` | stringa casuale lunga (**segreto**), protegge la pulizia |
| `SUPABASE_SERVICE_ROLE_KEY` | già presente: serve alla pulizia |

Non sono `NEXT_PUBLIC_*`: basta riavviare, niente rebuild.

- **Vercel**: Project → Settings → Environment Variables, poi *Redeploy*.
  `vercel.json` programma già la pulizia ogni notte alle 3:30 UTC; Vercel Cron
  invia da solo `Authorization: Bearer $CRON_SECRET`.
- **Docker**: nel file `.env` (`node scripts/genera-env.mjs` genera
  `CRON_SECRET`), poi `docker compose up -d app`. Per la pulizia aggiungi al
  crontab del server:
  ```
  30 4 * * * . /percorso/nolotrack/.env && curl -fsS -X POST -H "Authorization: Bearer $CRON_SECRET" http://127.0.0.1:8080/api/allegati/pulizia
  ```
- **Kubernetes**: `R2_ACCOUNT_ID`/`R2_BUCKET` in `config.env`, chiavi e
  `CRON_SECRET` in `secrets.env`; il CronJob `pulizia-allegati` è già incluso.

### 5. Database

- **Supabase cloud**: esegui `supabase/migrations/20261123_allegati_r2.sql` nel
  SQL Editor.
- **Self-hosting** (Docker/Kubernetes): automatico, è `database/ddl/095_allegati.sql`.

## Backup

I backup di `scripts/backup.sh` contengono i **metadati** degli allegati, non i
file. R2 è già ridondato da Cloudflare; per una copia indipendente:

```
rclone sync r2:nolotrack /backup/nolotrack-allegati
```

## Costi

R2 non fa pagare il traffico in uscita. Il piano gratuito include 10 GB di
spazio e 1 milione di scritture al mese: con foto ridimensionate (~300 KB)
sono decine di migliaia di scontrini.
